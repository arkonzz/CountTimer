# CountTimer · 番茄倒计时

桌面倒计时 + 番茄钟工具（WinForms / .NET 8 / AntdUI / SQLite）。界面可在中文和 English 之间切换。

## 功能

### 🍅 番茄钟（含事件倒计时）
- 专注 → 短休息 → 专注循环，每 N 轮自动插入长休息
- 圆环进度倒计时，阶段自动换色（专注红 / 短休绿 / 长休蓝）
- 开始 / 暂停 / 继续 / 跳过 / 重置；可用全局快捷键开始或暂停（默认 Ctrl+Alt+Space，可改）
- 托盘图标直接显示剩余时间，暂停时变暗；鼠标悬停可看阶段与剩余时间
- 可关联一个事件作为当前任务，专注完成通知会带上任务名
- 事件倒计时：事件的新增 / 编辑 / 删除，重复方式有 不重复 / 每天 / 工作日 / 每周 四种（工作日按法定节假日调休后的实际上班日算）。选中事件即自动开始倒计时，结束托盘气泡提醒；后台自动清理过期事件、滚动循环事件
- 阶段切换托盘气泡通知 + 系统提示音
- 统计：今日完成番茄数、累计专注分钟、近 7 天每日完成数（悬停可看某一天），存 SQLite `focus_session` 表
- 设置：专注 / 短休 / 长休时长、长休间隔轮数、自动开始休息 / 专注、提示音、深色主题、语言、全局快捷键、窗口置顶、开机自启、托盘显示时间

### 📝 小计
- 手动记录事件流水：输入内容 + 选择时间（默认当前时间），回车或点击添加
- 记录列表按时间倒序展示（SQLite `memo_record` 表），支持按日期筛选、行内删除
- 今日条数 / 总条数统计

### 📅 节假日
- 未来一年的节日倒计时：公历节日、农历节日（春节 / 元宵 / 端午 / 七夕 / 中秋 / 重阳）、除夕、清明（按太阳黄经计算）
- 法定放假与调休：倒计时到放假首日，标注放几天、哪几天补班；假期进行中显示还剩几天
- 自定义生日 / 纪念日：支持公历和农历，填了年份会显示周岁或周年
- 每月重复的日子（发薪日、还款日这类）：和节日排在同一条倒计时里，只显示下一次；当月没有这一天（29 / 30 / 31）按月末算，遇周末或法定放假可以设为提前或顺延到工作日（默认提前，按调休后的实际上班日算）

### 其他
- 关闭窗口最小化到托盘，托盘菜单可显示主界面 / 退出
- 记住窗口位置和大小；那块屏幕已不可用时回到右下角
- 可选开机自启，启动后直接进托盘
- 单实例运行

## 开发

```
dotnet build
dotnet run
dotnet test
```

`dotnet test` 运行 `CountTimer.Tests`，覆盖日期换算、放假安排数据的解析与校验、重复规则、每月重复的日子、快捷键、托盘图标等。

自测用的开关（环境变量）：

- `CT_E2E=1`：启动后自动跑一遍端到端自测，结果写到临时目录下的 `ct_e2e_result.log`
- `CT_DATA_DIR`：指定数据目录，自测时用它和真实数据隔离开

## 数据位置

`%LOCALAPPDATA%\CountTimer\`

- `ToDoDb.db`：事件、专注记录、小计、自定义的生日 / 纪念日
- `settings.json`：全部设置
- `holidays\`：法定节假日安排的缓存，每年一个 `年份.json`

旧版本把数据放在程序目录的 `Db\` 下，第一次启动新版本时会自动迁移到上面的位置。

## 法定节假日数据

来自开源数据集 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)（MIT，许可文本见 `Resources/Holidays/LICENSE.holiday-cn.txt`），内容取自国务院办公厅每年发布的通知。

- 程序内置了 2026、2027 两年的数据作为兜底，离线可用
- 启动后在后台联网更新今年和明年的安排：每 12 小时最多尝试一次，多个镜像依次尝试，全部失败不影响使用
- 下一年的安排一般在年底公布，公布后程序会自动获取；等不及时也可以把数据集里对应的 `年份.json` 手动放进 `holidays\` 目录
