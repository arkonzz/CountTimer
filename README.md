# CountTimer · 番茄倒计时

桌面倒计时 + 番茄钟工具（WinForms / .NET 8 / AntdUI / SQLite）。

## 功能

### 🍅 番茄钟（含事件倒计时）
- 专注 → 短休息 → 专注循环，每 N 轮自动插入长休息
- 圆环进度倒计时，阶段自动换色（专注红 / 短休绿 / 长休蓝）
- 开始 / 暂停 / 继续 / 跳过 / 重置
- 可关联一个事件作为当前任务，专注完成通知会带上任务名
- 事件倒计时整合：事件新增 / 编辑 / 删除（支持一次性与每日循环），选中事件即自动开始倒计时并在旁显示剩余时间，结束托盘气泡提醒；后台自动清理过期事件、跨天滚动循环事件
- 阶段切换托盘气泡通知 + 系统提示音
- 今日统计：完成番茄数、累计专注分钟（存 SQLite `focus_session` 表）
- 可配置：专注 / 短休 / 长休时长、长休间隔轮数、自动开始休息 / 专注、提示音开关（存 `Db/settings.json`）
- 明暗主题一键切换（设置区"深色主题"开关，随配置持久化）
- 界面自适应：窗口缩放时内容自动居中，圆环和倒计时字号随窗口大小缩放

### 📝 小计
- 手动记录事件流水：输入内容 + 选择时间（默认当前时间），回车或点击添加
- 记录列表按时间倒序展示（SQLite `memo_record` 表），支持行内删除
- 今日条数 / 总条数统计

### 其他
- 关闭窗口最小化到托盘，托盘菜单可显示主界面 / 退出
- 窗口默认停靠屏幕右下角、置顶
- 单实例运行

## 开发

```
dotnet build
dotnet run
```

数据文件：`Db/ToDoDb.db`（事件、专注记录）、`Db/settings.json`（番茄钟配置）。
